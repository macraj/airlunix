Persistence media

Loading

Boot files and selected persistent state share partition 1. The running root filesystem is in RAM.

Partition changes are durable immediately. Discarding RAM changes cannot undo them. No shrink, move, delete or format-existing-volume actions are provided.

Prepare a replacement SD

Not checked

While Airlunix continues from RAM, remove the unmounted boot card and insert one replacement microSD. Airlunix downloads the latest approved image directly from the official GitHub Release, verifies SHA-256, writes and reads back the card, then saves the current users and selected configuration.

The detected replacement card is completely overwritten. Keep power connected until verification and configuration save finish. This requires a published binary release; source-only Git tags are not installable images.

Mounted filesystems

Free capacity is shown only when measured. An unmounted filesystem is not silently mounted for monitoring.

Interactive accounts

Normal accounts do not receive administrative privileges. No password hashes are exposed.

Account changes apply in RAM. An administrator must explicitly save supported configuration for those changes to survive reboot.

System identity

Boot & network readiness

Kernel-relative measurements exclude bootloader time. A local SSH banner is distinct from external LAN reachability. Application readiness is not inferred from process presence.

Web Console footprint

One shared on-demand sampler serves all clients. History is bounded in RAM. Browser polling stops when the page is hidden. HTTPS sessions expire and are never saved.
